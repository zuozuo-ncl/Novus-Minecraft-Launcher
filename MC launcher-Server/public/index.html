# MC Launcher 版本管理 API 文档
# Base URL: http://localhost:5003

## 1. 检查更新 (客户端调用)
POST /api/check-update
# Request Body:
{
  "currentVersion": "1.0.0"
}

# Response (有更新):
{
  "updateAvailable": true,
  "latestVersion": "1.1.0",
  "allVersions": ["1.0.0", "1.1.0"]
}

# Response (无更新):
{
  "updateAvailable": false,
  "latestVersion": null,
  "currentVersion": "1.1.0"
}

## 2. 获取所有版本信息
GET /api/versions
# Response:
{
  "latest": "1.1.0",
  "versions": ["1.0.0", "1.1.0"]
}

## 3. 添加新版本
POST /api/versions
# Request Body:
{
  "version": "1.2.0"
}

## 4. 删除版本
DELETE /api/versions/:version
# 例: DELETE /api/versions/1.0.0

## 5. 设置最新版本
PUT /api/versions/latest
# Request Body:
{
  "version": "1.2.0"
}

## 版本比较规则
- 使用语义化版本比较 (Major.Minor.Patch)
- 1.10.0 > 1.2.0 > 1.0.0
- 支持任意位数: 1.0.0.0 > 1.0.0
